# Solar AI Optimizer — Home Assistant Integration

HACS custom integration for the [Solar AI Optimizer](https://github.com/oraad/solar-ai-optimizer) app.

Requires **Home Assistant Core 2026.7.0+**, [HACS](https://hacs.xyz/), and a reachable Solar HTTP API (pairing code, or Supervisor discovery on HAOS).

## Quick start

1. **Add to HACS** — [![Open your Home Assistant instance and open a repository inside the Home Assistant Community Store.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=oraad&repository=solar-ai-integration&category=integration)  
   Install **Solar AI Optimizer**, then restart Home Assistant.
2. **Configure** — [![Open your Home Assistant instance and start setting up a new integration.](https://my.home-assistant.io/badges/config_flow_start.svg)](https://my.home-assistant.io/redirect/config_flow_start/?domain=solar_ai_optimizer)  
   Enter the Solar host URL and pairing code from Solar Settings.

Buttons require [My Home Assistant](https://my.home-assistant.io/) configured in your browser. See the [integration guide](home-assistant-integration.md) for manual steps and troubleshooting.
