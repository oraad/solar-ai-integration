# تكامل Home Assistant المخصص

يتطلب **Home Assistant Core 2026.7.0+**.

مستودع HACS للتكامل فقط. ثبّت تطبيق Solar من [`oraad/solar-ai-optimizer`](https://github.com/oraad/solar-ai-optimizer).

**التثبيت:** أضف `https://github.com/oraad/solar-ai-integration` في HACS كـ **Integration** (وليس Add-on).

التفاصيل الكاملة في [النسخة الإنجليزية](home-assistant-integration.md).

**الترحيل:** إذا أضفت `oraad/solar-ai-optimizer` كتكامل HACS، أزله وأضف `oraad/solar-ai-integration` بدلاً منه.
