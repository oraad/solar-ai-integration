# Intégration Home Assistant personnalisée

Nécessite **Home Assistant Core 2026.7.0+**.

Ce dépôt est l'intégration HACS uniquement. Installez l'application Solar depuis [`oraad/solar-ai-optimizer`](https://github.com/oraad/solar-ai-optimizer).

**Installation :** ajoutez `https://github.com/oraad/solar-ai-integration` dans HACS en tant qu'**Integration** (pas Add-on).

Voir la [version anglaise](home-assistant-integration.md) pour les détails.

**Migration :** si vous aviez ajouté `oraad/solar-ai-optimizer` comme intégration HACS, retirez-le et ajoutez `oraad/solar-ai-integration`.
